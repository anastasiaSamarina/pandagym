# Спецификация (кратко)

**Решения:** локальное хранение в браузере (IndexedDB) + синк xlsx в приватный репозиторий GitHub; ванильный JS без сборки; PWA для офлайна.
**Сущности:** цикл (лист Excel) → тренировка (дата, день, план тренера, заметка) → блоки: «круги» (вес × повторы + комментарии), «свободный», «интервал» (табата: работа/отдых/раунды/движения/таймер).
**Сравнение:** с последним более ранним выполнением того же упражнения, по номеру круга; зелёный лучше, красный хуже, чёрный без изменений; облегчение инвертирует вес.
**Аналитика:** вес по времени, объём по тренировкам и неделям, плато, нагрузка по мышцам (кругов за 4 недели), календарь и цель недели, поиск «делала ли раньше».
**Замеры:** вес, ОТ, ОГ, ОБ — графики и стрелки изменений без цветовой оценки.
**Не делаем:** личные рекорды, 1RM, внешние базы упражнений (мышцы подставляются по названию и правятся вручную).
**Офлайн:** оболочка в кэше service worker, данные в IndexedDB; без связи синк ждёт, pull-to-refresh сообщает об отсутствии сети.
**Без ИИ:** всё считается обычным кодом; файл читается глазами; «Проверка данных» находит битые даты и дубли.
