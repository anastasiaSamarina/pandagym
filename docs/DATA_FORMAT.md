# Формат файла workouts.xlsx

Файл ведёт приложение, но его можно открыть и править в Excel. Приложение подхватит правки при импорте/синке.

## Листы
- **Цикл 1, Цикл 2, …** — любой лист, имя которого не начинается с `_` и не равно `Замеры`. Один цикл = один лист. Новый цикл в приложении создаёт новый лист.
- **Замеры** — Дата | Вес, кг | ОТ, см | ОГ, см | ОБ, см.
- **_Упражнения** — справочник: Упражнение | Единица (повт/сек) | Облегчение (да — меньше вес = лучше, как в гравитроне) | Мышцы | Синонимы (через `|`).
- **_Настройки** — занятий_в_неделю, текущий_цикл, циклы.
- **_Удалённые** — служебный: какие тренировки удалены (нужен синхронизации, не трогай).
- **_Справка** — краткая памятка внутри файла.

## Лист цикла: одна строка = один круг
| Колонка | Значение |
|---|---|
| ID | одинаковый у всех строк одной тренировки; для новой придумай любой уникальный (например `w_ручная1`) |
| Дата | ГГГГ-ММ-ДД |
| День | А / Б / С / любое название |
| № | порядок упражнения в тренировке |
| Упражнение | название (одинаковое написание = одна история) |
| Тип | `круги`, `свободный`, `интервал`, `заметка`, `план` |
| Круг, Вес, Повторы / сек | для типа `круги`; вес пустой = свой вес; повторы — число (диапазон `14-16` в расчёты не идёт) |
| Комментарий круга | «с резинкой» и т.п. |
| Комментарий упражнения | в строке первого круга; для `свободный`/`интервал` — основной текст; для `заметка`/`план` — текст тренировки |
| Работа, с / Отдых, с / Раундов / Формат / Движения | для типа `интервал` (табата) |
| Медиа | имена файлов из папки `media/` репозитория, через `;` |
| Изменено | время последней правки (по нему синк выбирает свежую версию). Если правишь в Excel — поставь сегодняшнее ГГГГ-ММ-ДДTЧЧ:ММ |

## Как считается сравнение (зелёный/красный)
Для каждого круга берётся тот же по номеру круг из **последнего более раннего** выполнения этого упражнения (хоть вчера, хоть месяц назад). Вес/повторы больше → зелёный, меньше → красный, равно → чёрный. Круг, которого раньше не было, — зелёный. Для упражнений с «облегчением» вес сравнивается наоборот.
Объём = сумма (вес × повторы) по кругам; без веса и для времени — сумма повторов/секунд. Диапазон вида «14-16» считается рекомендацией тренера и в расчёты не входит (при импорте уходит в комментарий круга «рекомендация 14-16»).
Плато: за последние 4 выполнения ни разу не улучшились ни вес (макс.), ни объём (+3%) относительно самого первого из этих четырёх.

## Дополнительные колонки (версия 3)
В конце таблицы цикла три новые колонки (заполняются в строке первого круга упражнения):
- **Поля** — что вводится в упражнении: `вес, повторы, темп`.
- **Темп** — четыре числа через дефис: подъём, пауза вверху, опускание, пауза внизу (например `3-1-2-0`).
- **Ссылки** — ссылки на видео через пробел.
Старые файлы без этих колонок читаются как раньше. Поле «День» теперь — название тренировки (старые А/Б/С показываются как «День А»).
