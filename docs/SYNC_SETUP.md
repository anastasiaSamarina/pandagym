# Синхронизация телефон ↔ компьютер через GitHub (бесплатно)

Сервера нет: приложение само читает и пишет `workouts.xlsx` в твой приватный репозиторий через GitHub API. Делается один раз.
Точные названия пунктов на сайте GitHub могут отличаться — ориентируйся по смыслу.

1. Создай **два** репозитория:
   - `gym-app` — **публичный**, туда кладёшь файлы проекта (кроме `_private-data`). Включи Pages (Settings → Pages → ветка `main`, папка root).
   - `gym-data` — **приватный**, пустой (можно с README, чтобы появилась ветка `main`). Тут будут `data/workouts.xlsx` и `media/`.
   Pages из приватного репозитория на бесплатном тарифе обычно недоступен, поэтому код и данные разделены.
2. Создай токен: GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate.
   - Repository access: *Only select repositories* → `gym-data`.
   - Permissions → Repository permissions → **Contents: Read and write**.
   - Срок действия выбери максимальный (по умолчанию он ограничен; когда токен истечёт, приложение скажет об этом — создай новый).
3. В приложении (на каждом устройстве): Настройки → «Синхронизация с GitHub»: логин, `gym-data`, ветка `main`, путь `data/gym.json`, токен → «Проверить подключение» → «Синхронизировать сейчас».
   Первый раз файла в репозитории ещё нет — приложение создаст его само. Путь `data/gym.json` — рекомендуемый: приложение хранит там все данные в JSON (быстро, ничего не теряется). Если укажешь путь, заканчивающийся на `.xlsx`, синхронизация пойдёт через таблицу Excel, как раньше. Excel всё равно можно скачать в любой момент из Настроек.
4. Дальше всё автоматически: после правки через ~4 секунды уходит в GitHub, при открытии приложения подтягивается свежее.

## Важно
- Токен хранится только в браузере этого устройства. Не вставляй его в код и не пиши в публичные репозитории. Потеряла телефон — отзови токен на GitHub.
- Нет связи — всё сохраняется на устройстве и отправится, когда связь появится. Конфликты (правки на двух устройствах) сливаются по тренировкам: побеждает более свежая правка.
- Картинки и GIF лежат в `media/` приватного репозитория; сжимай GIF (приложение отказывается от файлов больше 8 МБ).

## Если синхронизация выдаёт ошибку
Настройки → «Журнал синхронизации» (или нажми на статус «ошибка» вверху → «Журнал»). Там по шагам записано, что делало приложение и что ответил GitHub. Кнопка «Скопировать» копирует журнал целиком — его можно показать тому, кто будет разбираться. Токен в журнал не попадает.
