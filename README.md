# Тренировки — личный дневник с аналитикой

Приложение без сервера и БД: открывается в браузере на компьютере и телефоне, ставится на домашний экран (PWA), работает без сети.
Данные хранятся в браузере и (по желанию) синхронизируются с Excel-файлом `workouts.xlsx` в твоём **приватном** репозитории GitHub.

## Что внутри
| Раздел | Что делает |
|---|---|
| Журнал | список тренировок, цель недели, ▲▼ сколько показателей выросло/упало |
| Тренировка | ввод кругов (вес × повторы), прошлые значения подсказкой, зелёный/красный, комментарии к кругам, копирование, удаление, «Поделиться» (картинка в буфер), фото/GIF, свободный блок, интервальная (табата) с таймером |
| Журнал | календарь месяца с отметками дней, кольцо «N из M за неделю», список тренировок выбранного месяца |
| Аналитика | поиск упражнения, вес и объём по времени, плато, нагрузка по мышцам |
| Замеры | вес, ОТ, ОГ, ОБ с графиками |
| Настройки | цель в неделю, циклы, импорт/экспорт Excel, GitHub-синк, тема |

## Запуск
Нужен любой статический веб-сервер, потому что браузер не запускает ES-модули с `file://`.
- Локально на Mac: двойной клик по `start.command` (если macOS не даёт открыть: правый клик → Открыть). Или вручную: в папке проекта `python3 -m http.server 8000` → http://localhost:8000
- Публикация: репозиторий `gym-app` (только этот код) → Settings → Pages → Deploy from branch → `main` / root.
  Страница будет доступна по адресу `https://<логин>.github.io/gym-app/`. Данные в этот репозиторий НЕ кладём.

## Первый запуск
1. Открой приложение → «Загрузить Excel с тренировками» → выбери свою старую таблицу. Один раз.
2. Прочитай отчёт импорта (что и почему нужно проверить), затем разделы «Упражнения» и «Проверка данных».
3. Хочешь синхронизацию телефон ↔ компьютер — `docs/SYNC_SETUP.md`.

## Карта проекта (чтобы разобраться без ИИ)
```
index.html            единственная страница
css/app.css           весь внешний вид, цвета — переменные в начале файла
js/main.js            запуск, переходы между экранами, статус синка
js/model.js           вся логика: сравнение с прошлым разом, объём, плато, слияние данных
js/store.js           хранение в браузере (IndexedDB)
js/sync.js            обмен с GitHub (скачать xlsx → слить → отправить)
js/xlsx-lite.js       чтение/запись .xlsx (внутри только JSZip для zip)
js/excel-io.js        формат файла + разбор твоей СТАРОЙ таблицы (parseLegacy)
js/view-*.js          экраны;  js/charts.js графики;  js/share.js картинка;  js/timer.js таймер
sw.js                 офлайн-кэш;  manifest.webmanifest  установка на экран
vendor/jszip.min.js   единственная сторонняя библиотека (лежит в проекте, из сети не грузится)
docs/                 описание формата Excel, инструкция по синку, спецификация
_private-data/        твой стартовый workouts.xlsx (в .gitignore, в публичный репо не попадёт)
```
Нет ни сборки, ни npm: правишь файл — обновляешь страницу. После правок поменяй `CACHE = 'gym-v1'` в `sw.js` на `gym-v2`, чтобы устройства взяли новую версию сразу.

## Если что-то пошло не так
- Excel можно править руками: `docs/DATA_FORMAT.md`. Потом в приложении: Настройки → Загрузить Excel → «Объединить».
- Резервная копия: Настройки → «Скачать workouts.xlsx» / «Резервная копия (JSON)».
- Проверка дат, дублей, выбросов: Настройки → «Проверка данных».
